# TM Tech Solutions - Industrial Automation & Fabrication

A modern, responsive website for TM Tech Solutions, showcasing industrial automation and fabrication services.

## 🚀 Features

- **Modern Design**: Clean, professional interface
- **Responsive**: Optimized for desktop, tablet, and mobile
- **Fast Loading**: Optimized images and performance
- **SEO Optimized**: Built for search engines
- **Animations**: Beautiful scroll-triggered animations
- **Mobile-First**: Perfect mobile experience

## 🛠️ Tech Stack

- **Next.js 14** - React framework
- **TypeScript** - Type safety
- **Tailwind CSS** - Styling
- **Framer Motion** - Animations
- **Next/Image** - Optimized images

## 📱 Pages

- **Home** - Hero section, products, services
- **About** - Company story, mission, team
- **Products** - Industrial products catalog
- **Services** - Engineering services
- **Contact** - Contact information

## 🚀 Deployment

### Vercel (Recommended)
1. Push code to GitHub
2. Connect to Vercel
3. Deploy automatically

### Netlify
1. Connect GitHub repository
2. Build settings: `npm run build`
3. Publish directory: `.next`

## 📦 Installation

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```
